Privacy Policy

Last updated: 21 November 2026

This policy covers Money Mechanics Uploader (the "tool"), a private, owner-only tool that publishes videos to the Money Mechanics YouTube channel. It is not offered to the public and has no other users.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information the tool accesses

  • Permission to upload videos, titles, descriptions, tags and thumbnails to the Money Mechanics channel (YouTube Data API, upload scope).
  • Read-only access to the Money Mechanics channel's own video details, statistics and YouTube Analytics reports.

How the information is used

  • To upload and schedule the channel's own videos.
  • To check that an upload finished processing, and to read the channel's own view statistics so the owner can pick better upload times.

What is stored, and what is shared

  • The OAuth credentials (client ID, client secret and refresh token) are stored privately by the channel owner and are never shared.
  • A log of the channel's own uploads (video ID, title, upload time) is kept so the same video is never posted twice.
  • The tool does not access any other person's Google or YouTube account, does not collect data about viewers, and does not sell or share any data with third parties.
  • The tool has no website login and does not place, read or store cookies or tracking technologies on anyone's device.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. If access is revoked, or if deletion is requested through the contact below, the stored credentials and any data obtained from YouTube API Services are deleted within 7 days. Statistics read from the API are not kept longer than 30 days unless refreshed.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions or deletion requests: contact us through the Money Mechanics YouTube channel.
